# 中文商务风格 PPT 生成

[English](README.md) | [简体中文](README.zh-CN.md)

> 用 python-pptx 生成可编辑的中文商务与品牌风演示文稿，内置一套完整的设计系统。

## 这是什么

> **脱敏说明。** 本 README 已经写成通用版本。技能文件本身可能仍带有内部域名、主机名或本机绝对路径。发布前请先跑一遍扫描（见 `opensource-preflight-audit`），把命中的内容替换掉。

这不是一个把幻灯片画成图的图片生成器。那种做法很常见，但它有个硬上限：产出改不了。

这里的交付物是一个真正的 `.pptx` 文件。文本框就是文本框，形状就是形状。你能打开接着改 —— 这就是草稿和能交出去的东西之间的区别。

## 为什么开源

我们做 PPT 是常态，而每次开头都要把同一套版式骨架重搭一遍。把它抽成一套可复用的系统，每个稿子省掉重复的半小时。

设计系统天生是可迁移的。把带品牌名的配色改掉之后，里面就没有我们的东西了。

## 能做什么

- **三套内置配色。** 覆盖不同的调性，每套都定义了正文色和强调色，不靠临时挑。
- **页眉、页脚、页码系统。** 统一应用，不是一页页单独设。
- **版式组件。** 卡片、对比、数据块、流程图，常见的页面形态不用手搭。
- **真正可编辑的产物。** 生成出来的文件和其他 `.pptx` 没有任何区别。
- **程序化控制。** 因为是代码，生成三十页统一样式和生成三页的力气是一样的。

## 环境要求

Python 3 · python-pptx

## 安装

```bash
git clone https://github.com/<你的用户名>/pptx-cn-brand.git
```

然后把整个目录放进技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.workbuddy\skills\pptx-cn-brand\` |
| macOS / Linux | `~/.workbuddy/skills/pptx-cn-brand/` |

没有构建步骤，重启对话即生效。

## 怎么用

说清要什么稿子：

- "做一个关于某某的商务 PPT，十页"
- "全篇用品牌配色"
- "按这份大纲生成页面"

它产出一个能直接打开编辑的 `.pptx`。

## 注意与边界

1. **有一套配色的名字带品牌信息。** 发布前改掉。
2. **版式是起点。** 生成出来的页面是拿来调的，不是拿来原样交的。
3. **字体可用性有影响。** 中文稿依赖渲染时机器上存在的字体；字体缺失会走默认，可能带动换行位置变化。
4. **python-pptx 写的是文件格式，不是渲染。** 需要看图的时候，用办公软件打开，或者另外渲染。
